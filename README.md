# Plastc

A neumorphic UI library for Tailwind CSS v4, cast as molded appliance plastic.

Parts you press stand up, parts that hold input sit in, and everything else stays flush. Depth is a token system with light and dark housings, visible focus, and text contrast checked against WCAG 2 and APCA.

## Use it

Plastc is one CSS file. It is not on npm yet.

1. Copy `src/plastc.css` into your project.
2. Import it after Tailwind in your entry stylesheet:

   ```css
   @import "tailwindcss";
   @import "./plastc.css";
   ```

3. Load Geist and Geist Mono:

   ```html
   <link href="https://fonts.googleapis.com/css2?family=Geist:wght@400..800&family=Geist+Mono:wght@400..600&display=swap" rel="stylesheet">
   ```

4. Light is the default. Add `data-housing="dark"` to `<html>`, or to any section, for dark.

Classes are unprefixed (`btn`, `field`, `panel`, `tabs`, `pager`) and every class is a Tailwind `@utility`, so variants work (`md:btn-lg`).

## Develop

The showcase and the reference screens are generated by `site/build.py` (Python 3) and styled by Tailwind.

```sh
npm install
npm run build   # writes site/index.html, site/screens/ and site/dist.css
npm run serve   # http://localhost:8765
```

The library itself is CSS only. `site/plastc.js` wires the demo pages and is not part of the library.
