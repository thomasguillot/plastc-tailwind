If you send more than a handful of invoices a week, the mouse is the slow part. Plastc now has a small set of shortcuts that cover the things you do most.

## The three to learn first

- <kbd class="kbd">N</kbd> starts a new invoice from anywhere in the app.
- <kbd class="kbd">/</kbd> moves focus to search, so you can find a customer or an invoice number without reaching for the sidebar.
- <kbd class="kbd">⌘</kbd> <kbd class="kbd">K</kbd> opens the command menu (on Windows and Linux, <kbd class="kbd">Ctrl</kbd> <kbd class="kbd">K</kbd>). Type what you want to do, such as “send reminder” or “export CSV”, and press Enter.

## Inside an invoice

Press <kbd class="kbd">Tab</kbd> to move from one line item to the next, and <kbd class="kbd">Enter</kbd> on the last row to add another. When the invoice is ready, <kbd class="kbd">⌘</kbd> <kbd class="kbd">Enter</kbd> sends it.

## Shortcuts and typing

Single-letter shortcuts only work when you are not typing in a field, so writing a note to a customer will never start a new invoice by accident. Press <kbd class="kbd">Esc</kbd> to leave a field and use them again.

The full list is in the command menu: open it and type “shortcuts”.
